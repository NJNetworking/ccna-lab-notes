### Which 802.1D optional features were built into the IEEE 802.1w standard and allow ports to move rapidly to the forwarding state? Choose three ###

#### POSSIBLE ANSWERS ####

* Root guard
* Portfast
* BPDU guard
* UplinkFast
* BackboneFast
* Loop guard
* Rootfast

##### MY ANSWER: b) portfast d) uplinkfast e) backbonefast  ######

### You want to configure an 802.1w edge port so that endpoint can send traffic over the network immediately. Which command should you use? ###

#### POSSIBLE ANSWERS ####

* ```spanning-tree link-type edge```
* ```spanning-tree mode edge```
* ```spanning-tree link-type portfast```
* ```spanning-tree portfast```

##### MY ANSWER: d) ```spanning-tree portfast``` #####
