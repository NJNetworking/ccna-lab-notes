### Router 1 learns 4 routes towards 192.168.1.0/24 through multiple routing protocols: RIP, EIGRP, OSPF & ISIS. Which routes will be added to the routing table? ###

#### POSSIBLE ANSWERS ####

* RIP route only
* EIGRP route only
* OSPF route only
* ISIS route only
* RIP & EIGRP 

##### MY ANSWER: b) EIGRP because by default best AD  ######

### Router 1 learns 2 routes to 172.16.0.0/16 via RIP, one via 10.0.0.1 and one via 10.1.0.1. Both are 5 hops away. Which routes will be added to the routing table? ###

#### POSSIBLE ANSWERS ####

* Both routes
* Only the route via 10.0.0.1
* Only the route via 10.1.0.1
* Neither route will be added because RIP's AD value is so high.

##### MY ANSWER: a) both because it will load-balance because RIP's metric is only based on hop distance so both will be 5 #####
