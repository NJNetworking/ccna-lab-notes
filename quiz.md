### Which is a well known port number defined by IANA? ###

#### POSSIBLE ANSWERS ####

* 1010
* 2001
* 4023
* 65000
 
##### MY ANSWER: a) 1010 ######

### According to IANA, what range of port numbers should hosts select from when randomly selecting a source layer 4 port number?

#### POSSIBLE ANSWERS ####

* Well-known
* Registered
* Ephemeral
* Reserved

##### MY ANSWER: c) Ephemeral #####

### Which of the following are features of TCP but not UDP (select three) ###

#### POSSIBLE ANSWERS ####

* L4 addressing
* Error recovery
* Session multiplexing
* Flow control
* Sequencing

##### MY ANSWER: b) d) & e) #####

### Which of the following Application Layer protocols use TCP to provide reliable communications (select three)

#### POSSIBLE ANSWERS ####

* SMTP
* SNMP
* HTTPS
* DHCP
* Syslog
* SSH

##### MY ANSWER: SSH, HTTPS and SMTP #####

### PC1 and SRV1 have an active TCP connection. SRV1 receives a TCP segment from PC1 with a sequence number of 27. When SRV1 acknowledges the segment, what will the value of the Acknowledgement field in the TCP header be? Assume a TCP window size of 1. ###

#### POSSIBLE ANSWERS ####

* 26
* 27
* 28

##### MY ANSWER: c) 28 #####
