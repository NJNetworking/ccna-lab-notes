### HTTP data sent from a YouTube web server is displayed via your web browser. This is an example of what? ###

#### POSSIBLE ANSWERS ####

* Adjacent-layer interaction
* Same-layer interaction
* Encapsulation
* De-encapsulation

##### MY ANSWER: c) Same-layer interaction  ######

### HTTP data has been encapsulated with three seperate headers and one trailer. What is the appropriate name for this PDU? ###

#### POSSIBLE ANSWERS ####

* Packet
* Segment
* Frame
* Data

##### MY ANSWER: c) Frame #####

### Which layers of OSI are most relevant to the network engineer? ###

#### POSSIBLE ANSWERS ####

* T - N - DL - P
* T - N - DL
* Network only
* A - P - S (Top 3)

##### MY ANSWER: a) T-N-DL-P (bottom 4) #####

### The link-layer of the TCP/IP model is equivalent to what layers(s) of the OSI model? ###

#### POSSIBLE ANSWERS ####

* Transport - Network
* Network - Datalink
* Datalink
* Datalink - Physical

##### MY ANSWER: d) Datalink - Physical (bottom two) #####

### Which layer of the OSI model provides H2H communications? ###

#### POSSIBLE ANSWERS ####

* Application
* Network
* Transport
* Data-link

##### MY ANSWER: c) Transport #####
